# Navidrome

将自己的 Navidrome 音乐服务器接入澜音，搜索、播放和下载库中的歌曲，浏览歌单、专辑、最近添加、常听及收藏，并显示歌词。需要已有的服务器和账号。

## 怎么用

1. 将本目录的 `plugin.js` 导入澜音插件管理，点击「使用」。首次使用会打开连接设置，填写服务器地址、用户名和密码，点击「验证并保存」。地址支持反向代理子路径，例如 `https://example.com/music`。
2. 在搜索页选择 Navidrome 搜歌；在首页「音乐库」选择 Navidrome 浏览内容，点击后使用澜音原有播放器和队列。
3. 导入歌单时，在澜音的歌单导入窗口选择 Navidrome，填写歌单 ID 或服务器上的歌单链接。以后可通过插件「配置」修改连接或刷新音乐库。

## 使用说明

- 默认播放原始音质，可选 MP3 128/192/320 kbps；转码需要服务器支持。服务器收藏为只读浏览，导入和本地收藏不会修改远端歌单。
- 勾选「在本机记住登录」后，下次启用可恢复连接；否则仅本次运行有效。「断开连接」清除本机登录记录。修改服务器密码后需重新连接。
- 公网服务器建议使用 HTTPS；连接内网服务器需开启对应选项并允许局域网访问。插件只请求所配置服务器的网络权限。
- 封面默认关闭。开启后，封面链接包含访问令牌，分享、导出或云同步带封面的歌单可能带出令牌，请按自己的使用场景决定是否开启。

需要支持 v2 插件和原生配置面板的新版澜音。服务器地址、证书、账号权限和转码配置需由你自行准备。
