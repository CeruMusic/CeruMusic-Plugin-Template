# 私人漫游 V3 · chaochao.roam.v3

仿网易云「私人漫游」的 **v3 版本**：以当前正在播放的歌为种子，在你已启用的**多个音乐源**之间持续推荐，队列快放完时自动补歌，可以一直听下去。

> 这是 v3 插件（`manifestVersion: 3`，`hostApi ^3.0.0`，面向澜音 2.5+）。
> v2 版本仍在 `plugins/v2/chaochao.roam/`，两者互不覆盖、可同时安装。

- 单文件插件，`plugin.js` 直接安装，无需构建
- 版本 0.7.1 · MIT · 作者 chaochao × DeepSeek
- **只做推荐与队列编排**，不提供音频：播放、歌词、封面、下载全部交给你已装的音源插件

## 和 v2 的区别

| | v2 (0.2.0) | v3 (0.7.1) |
| --- | --- | --- |
| 推荐范围 | 只用网易云（wy） | 已启用的**所有**音源（QQ / 网易云 / 酷狗 / 酷我 / 咪咕 / 汽水 / Apple Music / 聚合…） |
| 续歌触发 | 定时器轮询 | **v3 Hook**：`player.play` / `player.next` / `player.queueEnded`，零延迟、不吃 CPU |
| 曲风权重 | 29 类 | **43 类**（语种 6 / 风格 27 / 主题 10） |
| 探索度 | 无 | **0–100 滑条**：往右混入随机词检索 + 随机榜单，能听到更冷门的歌 |
| 推荐范围开关 | 无 | 全平台混合 / 单一平台，在权重抽屉顶部切换 |
| 界面 | native 面板 + schema 抽屉 | native 面板（沿用 v2 版式）+ web 抽屉 |
| 音源列表 | — | 记住上次扫到的平台，重启不用手动重扫；启动后 2.5/7/15/30 秒自动补扫 |

## 权限

声明 5 项，只在需要时申请，拒绝后不重复打扰：

- `music.read` 搜索并读取已安装音源的候选
- `music.control` 把选中平台的歌写进播放队列
- `player.read` 读取播放状态与队列
- `player.control` 追加 / 播放队列里的歌
- `player.intercept` 在切歌 / 队列结束时补歌（**运行时申请**）

不联网自建接口、不登录任何账号、不写任何外部服务；本地只存自己的配置与候选缓存。

## 安装

1. 设置 → 插件管理 → 添加插件 → 选择 `plugin.js`
2. 启用后到「设置 → 音乐源与音质」确认至少有一个音源插件在运行
3. 播放任意一首歌 → 侧栏「私人漫游」→ 点「开始漫游」
4. 想调口味：面板「曲风权重设置」

## 已知限制

- 音源插件没有「拉全库」接口，所以「探索度」用随机检索 + 随机榜单近似，不是真·全库随机
- 咪咕（mg）平台的音源插件（如聆澜 9.0.1）在播咪咕歌时会崩溃、被宿主停用，与本插件无关；可装配套的「咪咕屏蔽」插件规避
