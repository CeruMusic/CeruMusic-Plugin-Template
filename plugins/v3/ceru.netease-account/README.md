# 网易云账号 v3

CeruMusic v3 插件，使用宿主账号菜单和账号保险箱完成网易云登录与凭据管理。提供每日推荐、个人歌单、歌单导入、搜索、排行榜、歌词和播放解析。

## 安装与升级

在支持插件 API v3 的 CeruMusic 桌面中导入 `plugin.js`。此插件使用 ID `ceru.netease-account`，与旧 v2 插件 ID 相同，但 v2 桌面不能加载 v3 制品。

v3 不读取或迁移旧版插件保存的 `netease.session.v1` Cookie。升级后请从桌面顶部通用账号菜单重新登录网易云。安装前保留旧插件包和配置备份，以便需要时回退。

## 功能

- 通过宿主账号菜单扫码登录、切换和退出网易云账号。
- 将凭据保存在宿主账号保险箱，插件只使用绑定到网易云来源的凭据句柄。
- 提供每日推荐、个人歌单分页、歌单分类与搜索、歌单详情和歌单导入。
- 提供歌曲搜索建议、热搜、歌曲搜索、排行榜、歌词和音质信息。
- 根据当前账号权益检查播放权限。

每日推荐仅在选择 `wy` 音源且网易云账号及授权可用时显示。真实账号和扫码流程仍需在目标桌面上验证。

## 权限与来源

插件会请求网络访问、播放控制和网易云账号凭据权限。凭据请求限定到 `https://interfacepc.music.163.com`。实现参考与第三方许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
