# 音枢歌单同步（Yinshu 歌单同步）

把**桌面澜音（CeruMusic）**接入**音枢（Yinshu）歌单同步枢纽**：与手机**栖弦（CyShineMusic）**、**洛雪 LX-X** 等客户端**双向同步歌单**——本地新增/删除自动上传，其他设备的增删自动生效；也可以和朋友共用一个枢纽空间，一起维护同一份歌单。

## 功能和适用场景

**做什么**：澜音 v2 插件，是音枢枢纽的「澜音端适配器」。它把澜音本地歌单提交给枢纽合并，并把枢纽的合并结果导入澜音本地同名歌单。合并、删除判定、冲突处理全部由枢纽统一完成，插件不做本地合并。

| 场景 | 处理 |
|---|---|
| 本机新增歌曲/歌单 | 提交给枢纽，其他客户端同步后可见 |
| 其他设备新增歌曲/歌单 | 自动导入澜音本地同名歌单（超 300 首自动分批，顺序一致） |
| 本机删除歌曲/歌单 | 提交后枢纽判删，其他客户端消失 |
| 其他设备删除歌曲 | 枢纽判删后自动删除澜音本地歌曲（需宿主向插件开放删除接口，见「已知限制」；不可用时跳过且不回写，不会把删除复活） |
| 其他设备删除整个歌单 | 状态栏提示手动删除同名歌单 |

**适用场景**：同时使用澜音与栖弦 / 洛雪 LX-X、希望歌单互通的人；或想和朋友共享歌单「一起听」的人。

**不适合**：只想同步本地音频文件的人（插件只同步歌单引用，不传音频）；不想自建同步服务的人。

## 所需版本与安装方式

- 澜音 **2.0 及以上**（v2 插件：`hostApi ^2.0.0`、`logicRuntime ceru-js@1`、`uiSchema ^1.0.0`）。
- 需要先部署一个**音枢（Yinshu）**同步服务：<https://github.com/YechoY/YinShu>（`uv run yinshu` 一条命令启动，Windows / Linux / macOS 均可；栖弦连同一个服务）。
- 安装：**澜音 → 插件管理 → 导入插件 → 选择 `plugin.js`**（本目录里的这个文件就是成品，不需要自己构建）。
- 启用后按提示允许权限；打开插件「连接同步服务」设置页，填音枢地址与音枢账号密码，**保存并测试**通过后即可「立即同步」。多台澜音共用一个账号时，给每台填不同的设备名。

## 请求的权限与访问的服务

| 权限（宿主组） | 权限 key | 可选 | 用途 |
|---|---|---|---|
| `network.request` | `webdav-sync.http` | 否 | 访问**你自己填的**音枢服务地址，读写 `/ceru/sync-v1.json`（唯一的网络目标） |
| `network.private` | `webdav-sync.lan` | 是 | 音枢跑在本机/局域网地址时，宿主要求的额外授权（插件会自动申请） |
| `library.read` | `webdav-sync.read` | 否 | 读取本地歌单与曲目，生成提交视图 |
| `library.write` | `webdav-sync.write` | 否 | 把合并结果导入本地同名歌单 |
| `library.delete` | `webdav-sync.delete` | 是 | 其他设备删除歌曲时，自动删除澜音本地对应曲目 |
| `background.run` | `webdav-sync.background` | 是 | 开启「自动同步」后定时检测变化并后台同步（默认 3 分钟） |

**访问的服务**：仅你自建的音枢服务（你填的 http(s) 地址，HTTP Basic 认证）。**不访问任何第三方服务器，不采集任何数据。**

## 是否需要用户自己的账号或凭据

**需要**：音枢服务的**地址 + 账号 + 密码**（账号在音枢管理页或 `config.json` 中创建）。开启「记住配置」时账号密码只保存在澜音本机（插件存储），仅以 HTTP Basic 头发给你自己填的音枢地址。设备名可选（同一账号多台澜音时用于区分设备，避免同步互相干扰）。

## 已知限制

- **当前澜音 2.2.1 暂不能自动删歌**：宿主能力表里声明了 `playlists.removeTracks`，但插件 SDK（`@shiqianjiang/ceru-plugin-sdk` 0.3.12）的插件桥尚未把该接口暴露给插件（调用会抛 `removeTracks is not a function`）。插件会明确提示并跳过本地删除，同时**不回写枢纽**（不会把已删除的歌复活）。上游接线后，本插件无需更新即自动生效。
- **删除整个歌单**：宿主没有「删除歌单本体」的 API，插件只提示手动删除，不会误删也不会复活。
- **歌单以名称跨端对齐**：在澜音里给歌单改名会被视为「删掉旧的 + 新建一个」，内容保留但可能与原歌单断开关联。
- **自动同步不弹窗建歌单**：枢纽里有、本地没有同名歌单的歌单会跳过并常驻提示，点「立即同步」在弹框里新建同名歌单即可一次性导入。
