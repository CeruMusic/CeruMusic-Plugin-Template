# 洛雪歌单导入

把洛雪音乐（LX Music）导出的歌单文件（`.json` / `.lxmc`）导入澜音的本地歌单。

## 怎么用

1. 将本目录的 `plugin.js` 导入澜音插件管理，点击「使用」，按提示允许读取文件与写入歌单。
2. 打开「歌单」页面，点右上角 **导入** → **从洛雪歌单文件导入**，澜音会弹出一个居中面板。
3. 点「选择洛雪歌单文件」挑选文件，可多选：`.json` 与压缩的 `.lxmc` 都支持，面板会列出解析到的文件、歌单与歌曲数。
4. 勾选要导入的歌单（默认全选，可单独取消或一键全选/全不选），需要的话直接在行内改歌单名，然后点「导入选中的 N 个歌单」。
   - **每个歌单各建一个本地歌单**：逐个写入，每个歌单会弹出一次目标选择（在同一个已有歌单里选，就等于合并进去）；
   - **合并为一个歌单**：只确认一次，所有勾选的歌曲写进同一个歌单。

单曲超过 300 首的歌单会分批写入。中途取消后解析结果不会丢，再点一次「开始导入」会接着做，已经写完的歌单不会重复创建。

## 播放依赖

洛雪歌单只保存「平台 + 平台歌曲 ID」（`wy` / `tx` / `kw` / `kg` / `mg`），不含播放地址。导入时写入的是**公共平台引用**，
播放与歌词由你在澜音「音源设置」中选择的同平台音源插件负责，所以需要先启用一个支持该平台的音源插件，
并按该插件自己的说明完成登录或导入 LX 音源。洛雪里的「本地文件 / 曲库目录」等来源在澜音没有对应实现，
会被标记为不可播放，但标题、歌手、专辑等元数据会保留。

同一首歌从搜索加入歌单、和从洛雪歌单导入，写入的平台 ID 规则一致，不会重复入库。

## 权限

| 权限            | 用途                                                               |
| --------------- | ------------------------------------------------------------------ |
| `files.read`    | 只读取你通过文件选择器点选的洛雪歌单文件；插件没有任意路径访问能力 |
| `library.write` | 通过澜音现有的本地歌单服务写入歌曲，去重、持久化与云同步由软件负责 |

两者都是可选权限，首次使用时由澜音弹出授权。解析结果只保留在内存里，插件不建立自己的歌单库、
不上传任何内容，也不需要澜音账号之外的任何凭据。

## 版本要求

需要支持 v2 插件与插件导入菜单的澜音。其中「打开插件导入面板前先关闭『选择导入方式』」这一处修复
尚未随正式版发布，**在旧版客户端上导入面板会和选择框叠在一起**，手动关掉「选择导入方式」即可。
