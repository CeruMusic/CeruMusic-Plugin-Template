# 哔哩哔哩音源

把 B站视频当作音频在澜音中收听。支持视频与 UP主搜索、排行榜、分P合集、收藏夹导入、评论和字幕歌词；独立运行，无需额外音源服务的凭据。

## 怎么用

1. 将本目录的 `plugin.js` 导入澜音插件管理，点击「使用」，允许网络访问，并在音源选择器中选择「哔哩哔哩」。公开内容可直接搜索播放。
2. 需要个人收藏夹时，从插件的「配置」入口打开「B站账号」，用哔哩哔哩 App 扫码确认；也可填写自己的 Cookie 或 SESSDATA，点击「验证并保存」。二维码过期后点击二维码区域刷新。
3. 登录后，在侧边栏已有的「歌单」页查看 B站收藏夹。也可在歌单导入窗口粘贴收藏夹链接、视频链接或 BV号，每个分P可独立播放。

## 使用说明

- 支持 64k、128k、192k，具体取决于视频提供的音轨；字幕歌词仅在视频有可用字幕时显示。
- 勾选「在本机记住登录」可在重启后恢复；不勾选则仅本次运行有效。「退出登录」清除本机记录。请勿分享 Cookie 或 SESSDATA。
- 登录和网络请求均访问 B站服务；遇到风控、内容下架或权限限制时会提示原因，私人内容可能无法在匿名分享页面播放。
- 需要支持 v2 插件及原生歌单区块的新版澜音。插件只申请网络权限，不需要澜音账号或额外音源配置。
