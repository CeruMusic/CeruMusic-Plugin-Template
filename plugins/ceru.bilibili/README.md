# 哔哩哔哩音源

B站独立音源插件。从聆澜拆出后，搜索、播放和账号管理均独立运行；不需要聆澜卡密。

## 安装与登录

1. 在澜音插件管理中安装本目录的 `plugin.js`，然后点击“使用”。
2. 在音源选择器选择“哔哩哔哩”。公开内容可匿名使用。
3. 在插件卡片的配置入口打开“B站账号”，面板自动生成二维码，使用哔哩哔哩手机端扫描并确认。
4. 也可填写完整 Cookie、`SESSDATA=值` 或单独的 SESSDATA 值，点击“验证并保存”。保存成功后立即生效，无需重启。

二维码三分钟过期；关闭面板、重新获取或关闭插件会停止原来的轮询。登录失败不会覆盖原来的有效账号。

“在本机记住登录”开启后写入插件私有存储，关闭账号面板或重启澜音后会自动恢复；关闭该选项时登录仅在当前运行期间有效。恢复成功后账号页只显示当前账号和“退出登录”，不会重新生成二维码。“退出登录”清除本机记录，不会使其他设备退出登录。输入框不回显已存凭据，账号 Cookie 不写入发行 JS、分享解析器或界面状态。当前 Host 的插件存储是本地文件，**不是操作系统加密凭据库**。

## 功能

- 视频音乐搜索、建议、热搜、UP主搜索和投稿查询。
- 热门、分区榜、每周必看、入站必刷；视频分P合集浏览。
- 登录后将个人收藏夹直接显示在澜音既有“歌单”页，与本地、云歌单并列；不另开歌单抽屉。
- 收藏夹链接/编号、视频链接/BV号导入；每个分P独立播放。
- 封面、评论、字幕转为标准 `crlyric`，并提供歌词导出转换。
- 内嵌 B站图标；公开音频分享解析器只返回 URL，不上传个人 Cookie。

默认音质从低到高为 `64k / 128k / 192k`。请求的音轨不存在时明确提示，不将其他档位冒充所选音质。私人或必须登录的内容不保证能在匿名分享页面播放。

仅申请公网访问权限，用于 B站接口、字幕及用户主动触发的登录。不申请软件账号、歌单读写、局域网或任意文件权限；导入保存交由澜音现有界面完成。

## 兼容与验证

需要 Ceru v2 Host API `^2.0.0`、`ceru-js@1` 和正式发布的插件工具链 `0.3.5`。桌面端需支持 `playlistSections`、账号抽屉的 `qrcode` 和 `closeAction`；请先更新并重启桌面端。

已用实际 Node 插件沙箱验证 Cookie 即时更新、失败保留、扫码状态流转、退出与轮询取消，以及搜索、导入分页、分P、歌词和播放契约。真实接口验证了二维码申请与待扫码状态、搜索、分P及音频读取。**未替用户完成真实账号扫码确认**；音乐榜偶尔返回 B站 `-352` 风控，插件会显示具体原因。

本目录依照社区投稿规范只放成品及资料。开发工程位于本机 `G:\code\pluginclitest\哔哩哔哩音源`；不要把 Cookie、开发缓存或 `node_modules` 放到投稿目录。发行 JS 保留可读的打包代码及依赖版权声明。
