# 网易云账号

在澜音中登录自己的网易云账号，查看每日推荐和个人歌单，直接使用澜音的歌单详情、播放队列与下载功能。

## 怎么用

1. 将本目录的 `plugin.js` 导入澜音插件管理，点击「使用」，按提示允许网络访问。
2. 打开顶部账号胶囊菜单，点击「网易云账号」，用网易云音乐 App 扫码确认。登录成功后弹窗自动关闭，菜单显示头像、昵称及会员标记；悬停账号可退出登录。
3. 在首页查看「网易云推荐」，在侧边栏已有的「歌单」页查看「网易云歌单」。点击歌单即可浏览、播放，也可导入到澜音歌单。

## 播放与音质

本插件属于网易云（`wy`）音源。安装了其他网易云音源时，可在插件路由设置中指定网易云的播放实现，推荐和歌单中的歌曲也遵循该选择。选择本插件解析时使用你的网易云账号，会员、购买及地区限制以网易云实际授权为准。

下载选项显示歌曲支持的标准音质和接口返回的文件大小；未知大小不估算。可选音质同时受当前播放音源支持范围限制。

需要支持 v2 插件、账号菜单和原生歌单区块的新版澜音；本版本的播放路由与大小显示需更新桌面端。登录保存在本机插件私有存储，退出登录会清除；播放控制权限在使用时申请。
