# 栖弦歌单同步（WebDAV 双向）

让**手机栖弦（CyShineMusic）**与**桌面澜音（CeruMusic）**通过 WebDAV 双向同步歌单：桌面端的新增和删除会自动写回云端，手机端读到的就是同一份歌单。

## 功能和适用场景

**做什么**：澜音 v2 插件。以手机栖弦原生就在用的 `sync-v1.json`（`<WebDAV地址>/CyShineMusic/sync-v1.json`）作为共享桥，读它、合并它、按需写回它，从而在两款播放器之间同步歌单。

| 场景 | 处理 |
|---|---|
| 栖弦新增歌曲 | 导入澜音本地同名歌单（超 300 首自动分批，顺序与栖弦一致） |
| 澜音新增/删除歌曲 | 写回云端，栖弦下次同步读到（删除不可逆） |
| 澜音新增/删除整个歌单 | 写回云端创建/移除该歌单条目 |
| 栖弦删除歌曲/歌单 | 在澜音「待清理清单」里列出，**需你手动清理**（见下方"已知限制"） |

**适用场景**：同时用栖弦（手机）和澜音（桌面）听歌，希望两边歌单保持一致的人。手机栖弦需要已配置好同一个 WebDAV。

**不适合**：只想同步本地音乐文件的人（本插件只同步歌单，不传音频）；不使用 WebDAV 的人。

## 所需版本与安装方式

- 需要支持 v2 插件的澜音（清单声明 `hostApi ^2.0.0`、`logicRuntime ceru-js@1`、`uiSchema ^1.0.0`）。
- 安装：**澜音 → 插件管理 → 导入插件 → 选择 `plugin.js`**（本目录里的这个文件就是成品，不需要自己构建）。
- 前置：手机栖弦已配置**同一个** WebDAV 地址（AList 等）并至少同步过一次。

## 请求的权限与访问的服务

| 权限名 | 可选 | 用途 |
|---|---|---|
| `network.request` | 否 | 访问**你自己填的** WebDAV/AList 服务器，读取与写回 `sync-v1.json`（只有这一个网络目标） |
| `network.private` | 是 | 当 WebDAV 是局域网/本机地址时（如 `http://192.168.x.x:5244`）才需要；遇到时会向你申请一次 |
| `library.read` | 否 | 读取澜音本地歌单，用于按同名歌单匹配、避免重复导入 |
| `library.write` | 否 | 通过澜音现有的歌单服务把歌导入本地歌单（去重、持久化由软件负责） |
| `background.run` | 是 | 只在开启「自动同步」时需要：定时检测歌单变化 |

**只访问你填写的那个 WebDAV 地址，不访问任何第三方服务，不上传任何内容。** 本插件没有自己的服务器。

写入前会做并发保护：支持 ETag 条件写（`If-Match`）的服务器直接由服务器判定冲突；不支持则写回前重新下载比对内容哈希；写回后还会回读自校验一次，确保云端文件完整（若服务器支持 `MOVE`，则采用"先写临时文件→校验→替换"的原子写，栖弦永远读不到半成品）。

## 是否需要用户自己的账号或凭据

**需要，但只存本机**：

- 你需要自备一个 WebDAV 服务（推荐 AList）的**地址、用户名、密码**——也就是手机栖弦「数据同步」里填的那一套。
- 这些信息存在**澜音本机的插件存储**里，且只有在设置页勾选「在本机记住配置」时才会持久化；不勾选则每次填写。插件不把它们发送到除你填写的 WebDAV 之外的任何地方。
- 不涉及澜音账号、不涉及任何第三方登录。注意插件存储不是密码保险箱，请自行评估。

## 已知限制

- **栖弦端的删除无法自动生效**：澜音 v2 插件 SDK 没有提供"删除歌单/歌曲"的 API，所以栖弦删掉的内容只能在澜音的「待清理清单」里按歌单名手动清理一次。反向（澜音删除写回栖弦）是自动的。
- **自动同步不会替你新建歌单**：SDK 没有静默创建歌单的 API。云端有、澜音本地没有同名歌单时，自动同步会跳过并常驻提示，点一次「立即同步」在弹框里新建同名歌单即可全部导入，此后走增量。
- **只同步平台歌曲**：来源为 `wy / tx / kw / kg / mg` 的歌曲才会写回栖弦；本地文件、其它音源插件的歌曲会被跳过（状态里会给出数量）。
- **歌单按名称对齐（澜音侧）/ 按 id 对齐（栖弦侧）**：在澜音里给歌单改名会被视为"删掉旧的 + 新建一个"，内容保留但栖弦侧的封面/作者等附加字段会丢失。
- **封面只在导入时带一次**：之后在栖弦改封面不会回填到已导入的歌曲。
- 栖弦的同步文件没有歌曲级时间戳，无法做到精确的"最后写入者胜"，本插件以「墓碑 + 来源端」近似。
- 电脑时钟明显落后于手机会导致写回被手机判为"更旧"而覆盖，请保持系统时间正确。
