# 波点音乐 · 澜音 v2 插件

一个自包含的澜音（Ceru Music）2.0 音源插件：波点音乐账号、搜索播放、歌词、歌单、私人推荐电台、发现页歌单 / 排行榜 / 个性化推荐、歌曲评论。

- 插件 id：`lemon.bodian-music`
- 音源 id：`bd`
- 版本：1.7.0
- 作者：lemon

## 功能

| 功能 | 说明 |
| --- | --- |
| 扫码 / 手机号登录 | 波点 App 扫码（本地渲染二维码）或手机号验证码登录 |
| 音源 | 搜索、播放地址解析、歌词，支持 128k / 192k / 320k / flac 可解码档位 |
| 私人推荐 | 侧边栏「私人推荐」：替换队列、顺序播放，播到最后一首自动追加下一批推荐 |
| 发现页 · 歌单 | 宿主原生歌单页：分类目录、分类歌单、歌单搜索 |
| 发现页 · 排行榜 | 宿主原生排行榜页：榜单目录 + 榜单歌曲分页 |
| 发现页 · 发现 | 只保留账号个性化推荐（个性化歌单 / 偶遇心动单曲 / 心动收藏相似推荐） |
| 歌曲评论 | 对接澜音自带评论浮层，展示热门 / 最新评论与回复（只读） |
| 歌单同步 / 导入 | 我喜欢、自建、收藏歌单挂到澜音歌单页；支持歌单 ID / 链接导入 |

## 安装

1. 打开澜音 → 插件管理 → 从文件安装；
2. 选择本目录的 `plugin.js`；
3. 启用插件并按提示授权 `network.request`；使用私人推荐时再授权 `player.control`。

需要澜音 2.0 及以上（v1 不兼容 v2 插件）。

## 使用

1. **登录**：账号胶囊 → 波点音乐 → 扫码或手机号登录；凭据只保存在本机插件存储。
2. **播放**：在澜音搜索里选择音源「波点音乐」即可搜索、播放、看歌词。
3. **私人推荐**：点击侧边栏「私人推荐」立即开播；最后一首播完会自动接上新推荐。
4. **歌单 / 排行榜**：在澜音「发现」页选择「歌单」「排行榜」标签浏览；歌单详情与榜单歌曲都走澜音原生列表。
5. **发现**：同页「发现」标签只显示账号个性化推荐，点歌曲会从该首开始替换队列。
6. **评论**：播放波点歌曲后打开澜音评论入口，即可看到该歌曲的热门 / 最新评论。
7. **歌单同步**：登录后「歌单」页出现「波点音乐」区块；导入支持歌单 ID / 链接。

## 权限与隐私

- `network.request`：访问 `bd-api.kuwo.cn` / `mlyric.kuwo.cn`。
- `player.control`：私人推荐替换播放队列、切换顺序播放、追加下一批。
- 账号 uid / token / 设备号只保存在本机插件存储，不发送到除波点官方接口以外的服务。
- 仓库与发行文件中不包含真实账号凭据。

## 已知限制

- 澜音插件 API 没有「拉起全屏播放页」能力，播放页需按 F 或点底部播放条。
- 宿主 Web Surface 的 CSP 只允许 `data:` / `blob:` 图片，账号弹窗里的第三方头像会被拦截，插件用品牌色首字头像兜底。
- 澜音评论浮层是只读的，插件只接入评论读取；发布评论请用波点 App。
- 评论 `moduleId` 只接受 32 位正整数，超长 ID 的曲目会显示暂无评论。
- 私人推荐依赖波点公开推荐接口；接口调整时可能需要更新插件。
