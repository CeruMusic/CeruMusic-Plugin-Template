# 私人漫游 · chaochao.roam

仿网易云「私人漫游」：以当前正在播放的歌为种子，不断往队列尾部续相似歌曲，队列快放完时自动补，可以一直听下去。附带每天换一批的「每日推荐」。

- 单文件插件，无需构建，`plugin.js` 直接安装
- 版本 0.2.0，面向澜音 (CeruMusic) 2.0 的 v2 插件格式（`hostApi ^2.0.0`）
- 只做**推荐与队列编排**，不提供音频；播放交给已启用的「网易云音乐 (wy)」音源插件

## 功能

| 功能 | 入口 |
| --- | --- |
| 私人漫游：剩 5 首自动补 3 首 | 侧栏「工具 → 私人漫游」 |
| 每日推荐（每天 30 首，按日期缓存） | 侧栏「工具 → 每日推荐」 |
| 曲风权重（29 个曲风，0–100） | 设置 → 插件 → 私人漫游 · 曲风权重 |
| 不喜欢：歌曲永久拉黑 + 歌手 14 天冷静期 | 面板「不喜欢当前这首」 |
| 最近 7 天听过的不重复 | 自动生效 |
| 使用说明 / 注意事项 | 面板「公告」 |

## 推荐怎么来

```
当前播放歌曲 → 取网易云 songId
   ├─ /api/discovery/simiSong      相似歌曲（主体）
   ├─ /api/artist/top/song         歌手热门（稳住曲风）
   ├─ /api/playlist/list          按曲风取歌单 → /api/playlist/detail 抽歌
   └─ /api/playlist/detail        热歌榜（冷启动 / 兜底）
        ↓ 过滤：队列已有、最近推过、点过「不喜欢」
   queue.append(…, { permissionKey: 'playerCtl' })
        ↓ ref = { pluginId:'chaochao.roam', providerId:'wy', scope:'provider', id:<songId> }
宿主用你选的网易云音源解析播放
```

续歌有两条触发路径：

1. **事件驱动**（`queue.changed` / `player.changed`）：切歌时立刻检查，剩 5 首就补 3 首（垫到 8 首）；
2. **后台定时任务**：每 60 秒兜底检查，并提前把候选池攒满。

候选池是**提前联网攒好的**，所以「换一批」和补歌是几十毫秒级，不卡 UI；池子空了先用现成的补上，再后台重攒——宁可不合口味也不断粮。

## 防漂移

相似推荐会顺着上一首往下漂，播到钢琴曲后面十首都是钢琴曲。插件里做三件事：

- **识别**纯音乐：按标题 / 专辑 / 歌手里的关键词（钢琴、piano、八音盒、轻音乐、古典…）猜；
- **换味道**：一旦是纯音乐，接下来 3 批不收纯音乐，改从华语 / 流行 / 摇滚 / 民谣 / 电子 / 说唱 / 爵士 / 欧美 / 日语 / 粤语 / 影视原声 / ACG 里取；
- **语种均衡**：连续 3 首同语种（中文 / 日文 / 韩文 / 英文）就强制换语种。

三者都是软过滤，一首凑不齐时自动放宽，保证永远补得上歌。

## 同歌去重

除 songId 外，还按**歌名归一化**（去掉 `(Live)`、`（翻自 xx）`、`feat.`、`- Remastered` 等后缀）再拦一道，最近 300 首内的同歌不再推；翻唱 / 现场版 / 不同版权版本会被当成同一首挡掉，这是有意为之。

## 安装

1. 先装并启用一个**网易云 (wy) 音源插件**（例如聆澜音源），在「插件路由」里把 `wy` 指向它；
2. 澜音 → 设置 → 插件 → 添加插件 → 本地导入，选择 `plugin.js`；
3. 启用后按提示允许 4 组权限。

## 权限与网络

| 权限 | 用途 |
| --- | --- |
| `network.request` | 访问网易云公开 web 接口（`https://music.163.com/api/...`）取元数据 |
| `player.read` | 读当前播放歌曲与队列，用来判断还要补几首 |
| `player.control` | 往队列追加歌曲、切换播放模式与播放 |
| `background.run` | 每 60 秒兜底检查一次 |

- **不需要任何账号、Cookie 或 API Key**，也不写任何凭据；
- 只访问 `music.163.com` 一个域名的公开接口（宿主网络权限不按域名细分，这里是插件实际行为）；
- 本地持久化只有插件自己的 `roam.state`（权重、黑名单、播放记录、候选池），不上传。

## 依赖与兼容

- 需要澜音 2.0 及以上（v2 插件格式）；
- 需要一个提供 `wy` provider 的网易云音源插件；换别的音源插件，推荐流照样能用；
- VIP / 版权歌曲能否播放由音源插件决定，本插件只提供元数据与队列编排，内置的 `tracks.resolve` 只是兜底。

## 已知边界

- 用的是网页端公开接口，不是官方开放 API；接口变更或风控可能导致取数失败（会 toast 报错，队列不会被打乱）；
- 纯音乐识别是关键词启发式，会误判或漏判；
- 7 天不重复只覆盖插件运行期间记录到的播放；
- 后台检查最小周期 1 分钟（宿主限制），一首歌通常 3 分钟以上，足够在播完前补上。
